## Source limitation

No true original images exist. The only available source is the base64-embedded
JPEG recovered from the original single-file HTML: **1400×788, 4:4:4 chroma**.
These masters are therefore already lossy, and every encode below is generation
loss on top of an existing JPEG. SSIM is measured against that JPEG, which is the
best reference obtainable. 1400px is also a hard ceiling on output resolution —
no variant is upscaled beyond it.

## Method

Quality is **not** chosen to hit a file-size target. For each image and format the
encoder ladder is binary-searched for the *lowest* quality whose SSIM against the
reference still reaches 0.985. File size is whatever that produces.

Quality is searched at native 1400px, where artefacts are hardest to conceal.
Downscaled variants inherit the setting and are then verified with their own SSIM.
